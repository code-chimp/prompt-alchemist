# Project Documentation

Welcome to the Tauri v2 React Starter Application documentation. This folder contains living docs aimed at:

- New contributors getting up to speed quickly
- Future you, remembering project decisions and conventions
- LLM assistants, providing enough context to generate high‑quality changes safely

If you update architecture, scripts, or stack, please keep these docs in sync.

## How to use these docs with LLMs

 
- Share the Architecture page for context on the React ↔ Tauri boundary and typed command layer.
- Share the Tech Stack page for understanding dependencies and design decisions.
- Share the Development Guide for code patterns and conventions.
- Share the Testing Guide when asking for changes that require running or validating code.
- Share the Getting Started page for setup and workflow information.
- Share the Personalizing page when customizing the template for a new project.
- Share `TECH_DEBT.md` when planning CI/CD, security hardening, or other production-readiness work.
